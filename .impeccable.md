## Design Context

### Users
Silo App Links serves self-hosted Silo users and admins who need a fast launcher for related external services. The user page should make launching services obvious, while the admin page should make link maintenance calm and low-risk.

### Brand Personality
Working assumption: quiet, capable, media-native. The interface should feel like part of Silo rather than a separate marketing site or generic dashboard.

### Aesthetic Direction
Use a dark, restrained operations UI with a warm magenta accent inherited from the existing plugin. Avoid glassmorphism, generic glow-heavy dashboards, and decorative card nesting. Prefer compact surfaces, clear launch affordances, and resilient states.

### Design Principles
- Make each click outcome visible before the user clicks.
- Treat iframe blocking as expected behavior and provide a clear fallback.
- Keep admin workflows dense, direct, and touch-friendly.
- Share visual tokens across plugin surfaces so polish stays consistent.
- Preserve unresolved brand questions: confirm Silo colors/type, expected catalog size, and whether the magenta accent is official.
